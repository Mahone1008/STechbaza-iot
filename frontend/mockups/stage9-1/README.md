# KERUMO — статичний UX-макет Етапу 9.1, ревізія 2

Це переглянутий світлий прототип після зворотного зв'язку про надмірно
контрастну першу версію. Він не є production frontend і не викликає backend.

## Що змінилось

- світла нейтральна основа замість суцільного темного інтерфейсу;
- бірюзовий використовується лише як акцент, а не як підсвічування всього UI;
- головний екран поділено за задачами: стан → показники → графік → керування;
- аварії, stale/offline та критичні дії мають окремі семантичні кольори;
- навігація й контекст організації/об'єкта завжди видимі;
- керування винесено в окрему праву панель і не змішується з телеметрією;
- mobile layout зберігає той самий порядок пріоритетів.

## Запуск

```powershell
python -m http.server 3000 --directory .\frontend\mockups\stage9-1
```

Відкрити `http://127.0.0.1:3000/#device`.

Перемикач унизу дозволяє переглянути Вхід, Пристрої, Панель, Аварії та Стани.
Усі дані демонстраційні. Кнопки не надсилають реальних команд.
