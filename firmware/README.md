# Прошивка

Додано тестову firmware ESP32-S3 N16R8 / SU600: [`kerumo_v3`](kerumo_v3/).
Перший запуск — тільки читання, без двигуна. Покрокова підготовка Windows,
прошивання, сайт і критерії приймання: [V3 SU600 bench](../docs/v3-su600-bench.md).
Чинний драйвер — SU600; сумісність інших моделей не заявляється.

Firmware **0.6.0** відокремила драйвер від ядра й додає
[паспорт, профіль `suswe.su600.modbus` v1 та прив'язку команд](../docs/equipment-foundation-v1.md).
Мінімальна база цього equipment contract — backend 0.44.0 і міграція 0021;
поточний main — 0.46.0/0023. NVS отримав wrapper із hash;
старі журнали читаються зі збереженням sequence, але при зміні прив'язки
потрібне локальне підтвердження STOP. NVS не стирати; downgrade окремо планується.
Без managed manifest збережено legacy v2 і попередню стендову конфігурацію.

[Календарні запуски](../docs/control-schedules-v1.md) до 7 діб існують із 0.5.0;
`max_schedule_seconds=604800`, фіксовані часові межі й STOP збережені.

Сумісні [таймер і етапи](../docs/control-programs-v1.md) існують з 0.3.0,
виконуються локально та зберігають sequence при міграції NVS. Спочатку
оновити backend/БД та сайт за [чинною процедурою](../docs/control-programs-v1.md),
потім весь скетч по USB. NVS не стирати.
Збережено [діагностику 0.2.2](../docs/controller-diagnostics-v1.md)
та правила керування з 0.2.1:
[тривалі випробування з двигуном](../docs/v3-su600-extended-test.md)
через `ARM SU600 TEST`, без 60-секундного таймера, зі збереженням допуску після
штатного STOP. Перед увімкненням потрібні підготовка моторного захисту та перевірка
зупинки при втраті керування; типові прапорці firmware лишаються вимкненими.

30.09.2026 на V3 через Wi-Fi прийнято базові START/STOP/частоту, повторний
пуск і зупинки при втраті gateway, DISARM та знеструмленні ESP32.
[Фізичні докази, межі та відкриті питання](../docs/dossier-v3-su600-control-bench.md).
V4 та 4G поки не перевіряються — очікується модуль.
01.10.2026 зафіксовано таймер, п'ять етапів, продовження після F5 і STOP
на другому етапі 0.3.0; [повне приймання PROGRAM-01 ще відкрите](../docs/control-programs-v1.md).
Старі докази керування не замінюють перевірок переривання активної програми.

Прошивка для польових контролерів TechBaza.

Після аудиту 05.10 NVS і Modbus adapter винесено в окремі модулі.
У **0.7.0** додано окремий provisioning adapter: WPA2 setup з телефона,
HTTPS bootstrap, MQTT credentials і canonical manifest delivery. Зміна
hash/UID потребує локального підтвердження STOP; factory reset не стирає
safety journal. Legacy `config.local.h` лишається сумісним.
[Повна підготовка й фізичне приймання етапу 2](../docs/stage2-acceptance.md).
Фізичне приймання 0.7.0 залишається відкритим.

Поточний напрямок по обладнанню:
- ESP32-S3;
- ізольований RS485;
- Modbus RTU для зв'язку з частотними перетворювачами;
- Wi-Fi / 4G;
- дистанційне керування та телеметрія.

Прошивка повинна підтримувати модульну конфігурацію обладнання, щоб кожен об'єкт відображав лише реально встановлені можливості.
