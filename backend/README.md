# Backend

Серверна логіка платформи TechBaza IoT.

## Поточний стан

Перший мінімальний FastAPI-сервіс уже створено.

Доступний endpoint:

```text
GET /health
```

Він використовується для перевірки, що backend запущений і відповідає.

## Заплановані задачі

- API для пристроїв і MQTT-інтеграція;
- автентифікація та рольовий доступ;
- передавання команд контролерам;
- обробка телеметрії;
- аварії, події та діагностика;
- робота з PostgreSQL.
